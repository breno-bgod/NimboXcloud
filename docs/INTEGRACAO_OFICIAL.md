# NimboXcloud — Base oficial Alpha 0.0.1

O userscript principal é publicado como **Alpha 0.0.1**. O módulo de Touch HUD mantém sua versão interna `1.4.1`, pois é um componente separado carregado pelo userscript principal.

A base atual reúne painel NX, Central de Entradas, HUD, ajustes de streaming, monitoramento, giroscópio e touchpad experimentais. A presença de código não comprova funcionamento em todas as sessões ou dispositivos.

**Limitações:** validar controles mistos, sensores físicos, fullscreen, áudio/vídeo, estabilidade e Remote Play em sessões reais. Não há garantia de acesso a títulos, resolução ou qualidade específica.

Novas correções e relatos públicos serão acompanhados a partir de [Alpha 0.0.1](../CHANGELOG.md), preservando o histórico Git anterior.
